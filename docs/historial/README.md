# Carpeta `docs/historial`

## Propósito

Esta carpeta almacena documentación de proceso, entregas parciales y análisis previos que ya no forman parte de la documentación activa del producto, pero que se conservan como registro histórico del proyecto.

## Qué contiene

- Entregas de cambios parciales (ej. `ENTREGA-C09-C10.md`) que ya están reflejadas en `CHANGES.md`.
- Documentación de pilotos académicos con decisiones de entorno de prueba (ej. `piloto.md`).
- Análisis de competencia y discovery previos al desarrollo (si se mueven aquí desde `docs/discovery/`).
- Evidencias de integración de herramientas de desarrollo (skill/MCP) ya reflejadas en `AGENTS.md` y `.atl/skill-registry.md`.

## Qué NO contiene

- Documentación de usuario final ni de desarrollador del producto (esa vive en `knowledge-base/` y `openspec/`).
- Especificaciones canónicas (viven en `openspec/specs/`).
- Código fuente ni configuración de runtime.

> Esta carpeta es de solo lectura histórica. No se deben editar los archivos aquí para implementar cambios del producto; usar `knowledge-base/` y `openspec/` como fuentes de verdad.
